Claude 中文生成器

此工具只读取官方 /Applications/Claude.app 的版本、签名和 Gatekeeper 状态。
在您确认后，它会创建或更新独立的 /Applications/Claude 中文.app，不会修改官方 Claude.app。

中文副本使用独立数据目录：
~/Library/Application Support/Claude Desktop zh-CN

中文副本为临时签名，可能无法通过 Claude Code、Cowork、Cockpit Tools、CC Switch 或其他第三方
工具的安装校验。需要这些能力时，请继续使用官方 Claude.app。
