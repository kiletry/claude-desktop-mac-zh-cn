## Claude 4.29 Gateway 配置恢复说明

- 中文副本的 Gateway 配置实际读取自 `~/Library/Application Support/Claude Desktop zh-CN-3p`。只把配置写入不带 `-3p` 后缀的主目录可能仍会进入官方登录流程。
- 退出中文副本并备份后，可将自己已有的有效 `configLibrary/` 复制到上述目录，并在该目录的 `claude_desktop_config.json` 中保留其他设置、合入 `"deploymentMode": "3p"`。
- [完整恢复步骤与回滚说明](https://github.com/kiletry/claude-desktop-mac-zh-cn/blob/main/docs/GRAPHICAL-INSTALLER.md#恢复已有-gatewayapi-配置claude-4290)。
- 已在本机验证 Gateway 首页、两个模型及配置健康检查；尚未发送推理请求测试。Cowork 的“无效安装”属于独立的签名限制。
- 本次仅补充恢复文档，安装包内容不变；生成器不会自动导入账号或 Gateway 凭据。不要上传 API Key、账号配置或本机备份。
